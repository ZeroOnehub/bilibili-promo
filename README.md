## ✨ 项目简介

这是一个介绍 **哔哩哔哩（bilibili）** 的单页宣传网站（课程作业版）。它把「弹幕、分区、UP 主、一键三连」这些 B 站特色，做成了能直接动手玩的交互，带你三分钟看懂 B 站。

整个页面被设计成**一支 05:20 的 B 站视频**：

- 页面底部有一条播放器进度条，**往下滚动 = 视频在播放**；
- 每个章节就是视频的一个**分 P**（P1 ~ P5），顶栏就是分 P 列表；
- 进度条上还有 B 站标志性的**高能进度条**，弹幕越多的章节波峰越高；
- 点 ▶ 按钮，页面会**自动往下播放**，适合上课投屏展示。

页面里还有两支**真的能播放的视频**：

- **P1《第 12 话「最后的夏天」》**：38 秒的动画名场面，黄昏山坡上的一句告白被烟花声盖住了；弹幕跟着剧情刷屏，你发的弹幕会钉在那一秒；
- **P3《【新人UP】第一次投稿，紧张到手抖，求三连！》**：B 站小电视第一次当 UP 主，按「拍 → 剪 → 投 → 被看见」走一遍，结尾是**互动视频**，选「一键三连」还是「下次一定」，结局不一样。

这两支视频没有用任何视频或音频文件：画面是 canvas 按时间实时画出来的，配乐和音效用 Web Audio 现场合成，所以能像真视频一样暂停、拖进度条、倍速、全屏。

项目只用了原生 **HTML + CSS + JavaScript**，没有任何框架和构建工具，双击 `index.html` 就能打开。

## 🎮 交互亮点

### 1. 两支真的能看的视频

**P1《第 12 话「最后的夏天」》**
- 滚到这里会静音自动播放，点左上角「🔇 点击开启声音」就能听到配乐、虫鸣和烟花声；
- 弹幕跟着剧情走：告白前弹出「前方高能」，烟花炸开时满屏「烟花你等一下！！」；
- 在下面发一条弹幕，它会**钉在当前这一秒**并保存在浏览器里，把进度条拖回去，它会准时再飘出来；
- 点「空降 00:21」这类弹幕，直接跳到名场面；
- 烟花里有爱心，也有小电视形状的。

**P3《【新人UP】第一次投稿，紧张到手抖，求三连！》**
- 点视频卡片的封面或标题，打开仿 B 站的视频页；左边四个步骤卡片能直接跳到视频里对应的章节；
- 封面像 B 站首页一样，鼠标左右移动就能预览视频内容；
- 视频页有弹幕列表（跟着播放高亮，点一条就跳过去）、视频章节、UP 主关注按钮和发弹幕输入框；
- 结尾是**互动视频**：选「一键三连」或「下次一定」，两个结局不一样；如果看视频时已经三连过，视频会「认出」你，直接进入感谢结局；
- 卡片和视频页的三连状态是同一份，在哪里点都会同步。

**播放器（两支视频共用）**
- 播放 / 暂停、拖动进度条、倍速（0.5x ~ 2x）、音量、全屏（不支持原生全屏时改用网页全屏）；
- 进度条按章节分段，鼠标悬停会显示那一帧的**预览画面**；
- 高能进度条按弹幕密度实时计算；
- 弹幕按轨道排布，后一条既不会压住前一条，也不会在屏幕里追上它；轨道满了就像 B 站一样丢掉放不下的；
- 支持滚动、顶部、底部三种弹幕和四种颜色。

### 2. 弹幕引擎（开场 / 片尾）
- 弹幕按**轨道**排布，同一轨道上一条弹幕尾巴没离开前不放下一条，避免重叠；
- 会自动**避开标题和按钮**所在的轨道，不挡内容；
- 开场可以**自己发弹幕**（最多 30 字），点输入框左边的「弹」可以选颜色和位置；
- 页面上所有「弹」按钮都是**全局弹幕开关**，互相联动。

### 3. 底部播放器（整页就是一支视频）
- 滚动位置实时换算成 `当前时间 / 05:20`；
- 进度条按章节**分段**，鼠标悬停显示「章节名 · 时间」，当前章节名显示在右侧；
- **高能进度条**：弹幕越多的章节，波形越高；
- 进度条可以**点击跳转**，也支持键盘操作；
- ▶ **自动播放**：页面以固定速度自动向下滚动，滚到底自动停止；滚轮、触摸、键盘翻页会自动暂停；
- 倍速按钮可以把自动播放调到 1.5x、2x 或 0.5x。

### 4. 一键三连
- 视频卡片上的 👍 点赞、🪙 投币、⭐ 收藏可以分别点击，数字实时变化；
- **长按点赞约 1 秒**触发一键三连（和 B 站 App 一样），也可以直接点「⚡ 直接三连」；
- 三连时有表情粒子爆开和提示气泡；分享按钮会真的复制本页链接；
- 片尾还可以给「这一页」三连、干杯。

### 5. 其他细节
- **小电视的眼睛跟着鼠标转**，点它会被「戳」到，还会说话；
- **分区贴纸**跟着鼠标倾斜，「🎲 帮我选一个」像转盘一样随机挑一个分区；
- **编年史竖着滚、横着走**，下面有年份导航，点一下跳到那一年；手机上自动改为竖排；
- **数字滚动**，外加一行按日均播放量估算的实时计数；
- **滚动出现**、站内锚点**平滑滚动**，顶栏高亮当前所在分 P。

## 🎨 设计风格

- **视觉语言**：浅色纸面背景 + 粗描边 + 硬投影的「贴纸风」，卡片带轻微随机旋转；
- **配色**：B 站粉 `#FF6699`、B 站蓝 `#00AEEC`、明黄 `#FFD23F`，墨色 `#18191C`，纸色 `#F6F4EF`；
- **字体**：Noto Sans SC（正文）、ZCOOL QingKe HuangYou（标题点缀）、Archivo Black（英文数字）、JetBrains Mono（时间码）；字体异步加载，加载失败会自动退回系统字体，不会卡住页面；
- **图标**：B 站小电视用内联 SVG `<symbol>` 绘制，全站复用，网站图标（favicon）也是它。

## 🛠 技术实现

| 方面 | 说明 |
| --- | --- |
| 技术栈 | 原生 HTML5 + CSS3 + ES5 JavaScript，**零依赖、零构建** |
| 样式组织 | CSS 自定义属性（`:root` 变量）统一管理颜色、描边、阴影、圆角 |
| 动画 | CSS 动画 + `requestAnimationFrame`；弹幕使用 transform 位移，性能友好 |
| 进度映射 | 滚动距离 ↔ 视频时间（`TOTAL = 320` 秒）双向换算，处理分段之间的缝隙 |
| 视频画面 | canvas 按时间 `render(ctx, t)` 实时绘制，每一帧只由 `t` 决定，所以能随意拖动、倍速、循环；随机效果都用固定种子，保证每次一样 |
| 视频声音 | Web Audio 现场合成配乐和音效，播放时提前 0.3 秒把要响的音排进时间轴；暂停或拖动时整条音轨换掉，声音和画面不会错位 |
| 弹幕排布 | 每条弹幕记着自己在片内的秒数；按轨道做碰撞检测，排不下就丢弃；自己发的弹幕存在 `localStorage` |
| 互动视频 | 片子由「主干 + 分支」组成，选完选项后把分支拼到时间轴后面，进度条、章节、弹幕一起重新计算 |
| 性能 | 不动的背景缓存成贴图，天空、泛光、烟雾先画在小画布上再放大，普通电脑上每帧只需几毫秒 |
| 视口检测 | `IntersectionObserver` 实现滚动出现、数字滚动、片尾弹幕触发 |
| 响应式 | 断点 `1100px` / `900px` / `760px` / `420px`，手机端编年史改为竖排 |
| 部署 | 纯静态文件，附带 `.nojekyll`，可直接用 GitHub Pages 托管 |

## 🚀 本地运行

项目是纯静态页面，无需安装任何依赖。

**方式一：直接打开**

```bash
git clone https://github.com/ZeroOnehub/bilibili-promo.git
cd bilibili-promo
# 双击 index.html，或：
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

**方式二：启动本地服务器（推荐，行为与线上一致）**

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js
npx serve .
```

然后在浏览器访问 <http://localhost:8000>。

## ♿ 兼容性与无障碍

- 支持 Chrome、Edge、Firefox、Safari 等现代浏览器，桌面端与移动端均已适配；
- 系统开启「**减少动态效果**」（`prefers-reduced-motion`）时，自动关闭持续动画和粒子特效，P1 的视频也不会自动播放；
- 浏览器规定声音必须由用户点击后才能播放：P1 默认静音播放，点「点击开启声音」后才出声；P3 是点开时直接有声音；
- 视频播放器可以完全用键盘操作，画面带文字描述（`aria-label`），弹幕列表可以用 Tab 逐条跳转；
- 进度条使用 `role="slider"` 并同步 `aria-valuenow`，可以用键盘操作；
- 按钮带 `aria-pressed` / `aria-label`，提示气泡使用 `aria-live`，装饰性弹幕层标记 `aria-hidden`；
- 眼睛跟随鼠标仅在精确指针设备上启用，不影响触屏体验。
